## 1. Краткое описание

**Голограмма (ДОЭ)** здесь — это матрица $128\times128$ значений фазы от $-\pi$ до $\pi$.
Её выводят на пространственно-временной модулятор света (ПВМС), через который проходит лазерный луч.
Свет дифрагирует и на заданных расстояниях от ПВМС собирается в изображения.

Нужно разработать **нейросеть**, которая по 4 объектным изображениям за один прямой проход
выдаёт один фазовый ДОЭ, восстанавливающий каждое изображение на своём расстоянии.
Классические методы (Герчберга–Сэкстона, Фиенап) требуют сотен итераций, нейросеть должна быть быстрее.

**Суть подхода:** обучение **без учителя** с физическим слоем. Эталонных ДОЭ нет, поэтому
выход сети пропускается через дифференцируемый расчёт дифракции Френеля, а функция потерь
сравнивает восстановленные изображения с исходными.

```
4 изображения ──► нейросеть ──► фаза φ ──► [слой Френеля на 4 расстояниях] ──► 4 восстановленных ──► потери
 (4×128×128)      (U-Net)     (128×128)         (фиксированный, без весов)        (4×128×128)     vs. исходные
```

## 3. Постановка задачи для машинного обучения

**Тип задачи:** обучение без учителя с дифференцируемым физическим слоем (physics-informed / unsupervised).

**Вход:** четвёрка изображений

$$X=(I_1,I_2,I_3,I_4)\in[0,1]^{4\times128\times128}.$$

**Модель:** сеть $f_\theta$, выход которой ограничен диапазоном фазы:

$$\varphi=\pi\cdot\tanh\big(f_\theta(X)\big)\in[-\pi,\pi]^{128\times128}.$$

**Физический слой** (фиксированный, дифференцируемый): $\hat I_m=\mathcal{P}_{z_m}(\varphi)$, $m=1..4$.

**Функция потерь:**

$$\mathcal{L}(\theta)=\frac{1}{4}\sum_{m=1}^{4}\Big[\big(1-\mathrm{КК}(I_m,\hat I_m)\big)+\alpha\,\big(1-\mathrm{ИСС}(I_m,\hat I_m)\big)\Big].$$

**Оптимизация:**

$$\theta^{*}=\arg\min_{\theta}\ \mathbb{E}_{X\sim\mathcal{D}}\ \mathcal{L}(\theta).$$

**Выходы метода:** ДОЭ $\varphi$ и четыре восстановленных изображения; качество оценивается по КК и ИСС.

**Важные свойства задачи:**

1. **Задача переопределена.** Неизвестных 16 384 (фаза $128\times128$), условий $4\times16\,384$ (яркости 4 изображений).
   Точного решения в общем случае нет, сеть ищет компромисс между плоскостями. Значения КК и ИСС, равные 1, недостижимы.
2. **Нет «правильных» ответов.** Эталонных ДОЭ нет, поэтому обучение идёт только через физический слой.
3. **Обобщение.** Если обучать только на 4 конкретных изображениях, сеть запомнит ответ (это будет оптимизация, а не метод).
   Основной результат — модель, обученная на разнообразном наборе четвёрок. Дообучение на конкретных 4 картинках — опциональное дополнение, его нужно чётко маркировать.

## 4. Физическая модель

### 4.1 Формула

Поле в плоскости восстановления на расстоянии $z$:

$$K(x,y)=\frac{e^{jkz}}{j\lambda z}\;e^{\frac{j\pi}{\lambda z}(x^2+y^2)}\cdot\mathrm{FFT}\!\left\{H(u,v)\,e^{\frac{j\pi}{\lambda z}(u^2+v^2)}\right\},\qquad H(u,v)=e^{j\varphi(u,v)}.$$

Здесь $k=\frac{2\pi}{\lambda}$, $(u,v)$ — координаты в плоскости ПВМС, $(x,y)$ — в плоскости восстановления.

Для изображения нужен только **модуль** поля, поэтому множители с чисто фазовым вкладом
($e^{jkz}$, $j$, $e^{\frac{j\pi}{\lambda z}(x^2+y^2)}$) можно опустить:

$$|K(x,y)|=\frac{1}{\lambda z}\,\Big|\mathrm{FFT}\big\{e^{j\varphi(u,v)}\,e^{\frac{j\pi}{\lambda z}(u^2+v^2)}\big\}\Big|.$$

### 4.2 Дискретизация

Сетка плоскости ПВМС: $u_n=(n-N/2)\,\Delta u$, $N=128$, $\Delta u=10$ мкм.
Шаг в плоскости восстановления (свойство одного FFT):

$$\Delta x_m=\frac{\lambda z_m}{N\,\Delta u}.$$

| $z$, мм | $\Delta x$, мкм | Поле зрения $N\Delta x$, мм |
|---|---|---|
| 24,1 | 10,02 | 1,28 |
| 25,3 | 10,52 | 1,35 |
| 26,5 | 11,02 | 1,41 |
| 27,7 | 11,51 | 1,47 |

Масштаб в плоскостях разный, но сравнение идёт попиксельно по массивам $128\times128$, поэтому это не мешает; это лишь одна из причин конфликта между плоскостями.

### 4.3 Проверка условия дискретизации (алиасинг)

Квадратичная фаза $e^{\frac{j\pi}{\lambda z}u^2}$ имеет локальную частоту $\frac{u}{\lambda z}$. На краю апертуры $u_{max}=0{,}64$ мм;
частота Найквиста $\frac{1}{2\Delta u}=5\cdot10^{4}$ 1/м.

| $z$, мм | $\frac{u_{max}}{\lambda z}$, 1/м | Доля от Найквиста |
|---|---|---|
| 24,1 | 49 920 | 99,8 % |
| 25,3 | 47 550 | 95,1 % |
| 26,5 | 45 400 | 90,8 % |
| 27,7 | 43 430 | 86,9 % |

Все значения ниже Найквиста, но при $z=24{,}1$ мм запас почти нулевой. Это значит, что условия задачи подобраны «на грани»,
поэтому квадратичную фазу нужно считать в **float64** (потом приводить к complex64), иначе накопится ошибка.

### 4.4 Эталонная реализация физического слоя (PyTorch)

```python
import math
import torch

def _quad_kernel(N, dx, wavelength, z, device):
    c = (torch.arange(N, device=device, dtype=torch.float64) - N / 2) * dx
    U, V = torch.meshgrid(c, c, indexing="ij")
    return torch.exp(1j * math.pi / (wavelength * z) * (U**2 + V**2)).to(torch.complex64)

def fresnel_amplitude(phase, z, wavelength=532e-9, dx=10e-6):
    """phase: (B,1,N,N), радианы  ->  |K|: (B,1,N,N) в плоскости z."""
    N = phase.shape[-1]
    quad = _quad_kernel(N, dx, wavelength, z, phase.device)
    field = torch.exp(1j * phase) * quad
    K = torch.fft.fftshift(
        torch.fft.fft2(torch.fft.ifftshift(field, dim=(-2, -1))), dim=(-2, -1)
    )
    return K.abs() / (wavelength * z)

def reconstruct(phase, zs=(24.1e-3, 25.3e-3, 26.5e-3, 27.7e-3), **kw):
    """-> (B,4,N,N): амплитуды во всех плоскостях."""
    return torch.cat([fresnel_amplitude(phase, z, **kw) for z in zs], dim=1)
```

Ядро `_quad_kernel` лучше кэшировать (оно зависит только от $z$ и $N$).
Физический слой считать в fp32/fp64, **не** в fp16 (mixed precision включать только для сети).

### 4.5 Нормировка восстановленного изображения

По ТЗ сохраняются **модули значений** поля, то есть восстановленное изображение это амплитуда $|K|$ (а не интенсивность $|K|^2$).

Метрики сравнивают яркости, поэтому правило нормировки нужно **зафиксировать один раз** и использовать одинаково в обучении и в финальной оценке.
ТЗ способ нормировки не задаёт, поэтому рабочее решение (см. [открытые вопросы](#15-открытые-вопросы)):

$$\hat I_m=\frac{|K_m|}{\max|K_m|}\in[0,1],\qquad \text{png}=\mathrm{round}\big(255\,\hat I_m\big).$$

Финальные метрики считаются по сохранённым 8-битным png восстановленных изображений и 8-битным исходным изображениям.

### 4.6 Квантование ДОЭ

ДОЭ сохраняется в 8 бит:

$$p=\mathrm{round}\!\left(255\cdot\frac{\varphi+\pi}{2\pi}\right),\qquad \varphi_q=\frac{2\pi\,p}{255}-\pi.$$

**Финальные восстановленные изображения считаются от $\varphi_q$ (после чтения png), а не от «чистого» $\varphi$.**
Ошибка квантования небольшая (шаг $\frac{2\pi}{255}\approx0{,}025$ рад), но её нужно учесть при проверке.

## 5. Метрики качества

Для каждой из 4 пар (исходное $A$, восстановленное $B$):

**Коэффициент корреляции Пирсона** (инвариантен к масштабу яркости):

$$\mathrm{КК}=\frac{\sum_{i,j}(A_{ij}-\bar A)(B_{ij}-\bar B)}{\sqrt{\sum_{i,j}(A_{ij}-\bar A)^2\ \sum_{i,j}(B_{ij}-\bar B)^2}}.$$

**Индекс структурного сходства:**

$$\mathrm{ИСС}=\frac{(2\bar A\bar B+c_1)(2\sigma_{AB}+c_2)}{(\bar A^2+\bar B^2+c_1)(\sigma_A^2+\sigma_B^2+c_2)}.$$

Для обоих идеал равен 1.

Реализация:
- обучение: КК самописный (3 строки на torch), ИСС — `pytorch_msssim.ssim` (дифференцируемый), `data_range=1.0`;
- финальная оценка: `skimage.metrics.structural_similarity` и `numpy.corrcoef`/`scipy.stats.pearsonr` на 8-битных png
  (так воспроизведёт любой эксперт). Расхождение обучающего и финального ИСС в третьем знаке — норма, но его надо проверить.

## 6. Данные

**Ключевой вопрос:** в итоге оцениваться будут «4 исходных объектных изображения». Если организаторы выдают их заранее — они и есть тестовая четвёрка.
Если нет, модель должна работать на **любых** четвёрках. В обоих случаях основной режим — обобщающая модель.

**Обучающий набор:** множество случайных четвёрок одноканальных изображений $128\times128$, значения в $[0,1]$.

Рекомендуемая смесь (на выбор, можно комбинировать):

| Источник | Зачем | Примечание |
|---|---|---|
| MNIST / Fashion-MNIST | простые контрастные объекты, быстрая отладка | апсемплинг $28\to128$ (bicubic) |
| CIFAR-10 / STL-10 в градациях серого | естественные текстуры | апсемплинг до 128 |
| Свои тестовые картинки (логотипы, фигуры, текст) | близость к реальной проверке | 20–50 штук |
| Синтетика (круги, линии, шум) | регуляризация, разнообразие | генерируется на лету |

Правила:
- четвёрки формируются **случайным выбором 4 разных картинок** на лету (`Dataset.__getitem__`), так число комбинаций огромно;
- разбиение: обучение / валидация / тест, **без пересечения картинок**;
- тестовая четвёрка (когда будет известна) в обучение не попадает;
- все изображения приводятся к `float32`, диапазон $[0,1]$, форма `(4,128,128)`.

Формат загрузки/сохранения png: одноканальный 8 бит (`PIL.Image.open(...).convert("L")`), никакого RGB.

## 7. Архитектура и функция потерь

### 7.1 Сеть

**Базовый вариант (v1):** U-Net, вход 4 канала, выход 1 канал.

- кодировщик: 4 уровня, каналы $32\to64\to128\to256$, блоки Conv–BatchNorm/GroupNorm–ReLU, MaxPool;
- декодировщик: симметричный, skip-соединения;
- выход: $\varphi=\pi\tanh(\cdot)$;
- параметров порядка единиц миллионов, на T4 одна эпоха по десяткам тысяч четвёрок занимает минуты.

**Улучшенный вариант (v2, если хватит времени):** подать на вход не только сами изображения, но и их
**обратное распространение** в плоскость ПВМС. Для каждого $I_m$ с нулевой/случайной фазой посчитать поле,
распространённое назад на $z_m$, взять амплитуду и фазу как дополнительные каналы (итого до 12 каналов).
Это даёт сети физический «подсказку», обычно ускоряет сходимость.

### 7.2 Потери

$$\mathcal{L}=\frac{1}{4}\sum_m\Big[(1-\mathrm{КК}_m)+\alpha(1-\mathrm{ИСС}_m)\Big]+\beta\cdot\mathrm{MSE}(I_m,\hat I_m).$$

- старт: $\alpha=1$, $\beta=0$; при нестабильности первых эпох добавить $\beta\in[0.1,1]$;
- опционально штраф на равномерность качества по плоскостям: добавить $\gamma\cdot\max_m(\text{потеря}_m)$ или дисперсию потерь по $m$, чтобы одна плоскость не страдала в пользу других.

### 7.3 Обучение

| Параметр | Значение по умолчанию |
|---|---|
| Оптимизатор | Adam, lr $=10^{-3}$, затем cosine decay до $10^{-5}$ |
| Батч | 16–32 четвёрки |
| Эпохи | 30–100 (по скорости) |
| Точность | сеть — AMP (fp16) допустимо; физический слой — fp32 |
| Валидация | каждую эпоху: средние КК и ИСС по 4 плоскостям |
| Чекпоинты | лучший по валидационному (КК+ИСС)/2, плюс последний |
| Seed | фиксировать (`torch`, `numpy`, `random`) |

Дополнительно (опционально): квантование в цикле — добавлять к $\varphi$ равномерный шум $\pm\frac{\pi}{255}$ или использовать straight-through-оценку округления на последних эпохах.

## 8. Базовые методы для сравнения

Нужны, чтобы (а) проверить физику и (б) честно показать выигрыш нейросети.

1. **Многоплоскостной алгоритм Герчберга–Сэкстона** (из презентации — классика): случайная начальная фаза → для каждой плоскости распространить поле,
   заменить амплитуду на целевую (фазу оставить), вернуть в плоскость ПВМС, усреднить поля по плоскостям, оставить только фазу; повторить 100–300 итераций.
2. **Прямая оптимизация фазы градиентом** (самый сильный и простой ориентир): взять тот же дифференцируемый слой Френеля, сделать $\varphi$ обучаемым
   тензором для конкретной четвёрки и минимизировать $\mathcal{L}$ через Adam ~300–1000 шагов. Это «потолок», который можно ожидать от метода на данной задаче,
   и он же показывает, какие значения КК/ИСС вообще достижимы.
3. **Нейросеть** (наш метод): один прямой проход, измерить время синтеза и сравнить со временем (1) и (2).

Сводная таблица для отчёта:

## 12. Проверки корректности (тесты)

Выполнить **до** запуска обучения; они ловят основные ошибки физики.

1. **Сохранение энергии.** Для любой фазы: $\sum|K|^2\,(\lambda z)^2 = N^4$ (теорема Парсеваля при фазовом ДОЭ с единичной амплитудой).
2. **Одна плоскость.** Прямая оптимизация фазы на *одном* изображении, $z=24{,}1$ мм: КК должен быть очень высоким (>0,9). Если нет, ошибка в физике.
3. **Четыре плоскости.** Прямая оптимизация на четвёрке: даёт реалистичный потолок. Значения КК/ИСС заметно ниже, чем для одной плоскости, это нормально.
4. **Тривиальная фаза.** $\varphi\equiv0$: на выходе должна получаться изотропная картина «sinc-подобного» вида, без NaN.
5. **Круговой тест.** `phase → png → phase`: максимальная ошибка не больше $\frac{\pi}{255}$.
6. **Согласованность метрик.** КК и ИСС из `torch` и из `numpy/skimage` на одних и тех же данных отличаются не более чем на $10^{-3}$.
7. **Диапазон.** Все выходы сети лежат в $[-\pi,\pi]$, все восстановленные — в $[0,1]$, без NaN/Inf.
8. **Размер и тип png.** Все сохраняемые файлы: `mode == "L"`, `size == (128,128)`.

## Приложение А. Минимальный пример функции потерь

```python
import torch
from pytorch_msssim import ssim

def pearson_cc(a, b, eps=1e-8):
    a = a - a.mean(dim=(-2, -1), keepdim=True)
    b = b - b.mean(dim=(-2, -1), keepdim=True)
    num = (a * b).sum(dim=(-2, -1))
    den = torch.sqrt((a**2).sum(dim=(-2, -1)) * (b**2).sum(dim=(-2, -1))) + eps
    return num / den                                    # (B, C)

def doe_loss(target, recon, alpha=1.0, beta=0.0):
    """target, recon: (B,4,N,N) в [0,1]."""
    cc = pearson_cc(target, recon)                      # (B,4)
    l = (1 - cc).mean()
    if alpha > 0:
        s = torch.stack([ssim(target[:, m:m+1], recon[:, m:m+1],
                              data_range=1.0, size_average=True)
                         for m in range(target.shape[1])])
        l = l + alpha * (1 - s).mean()
    if beta > 0:
        l = l + beta * torch.mean((target - recon) ** 2)
    return l
```
